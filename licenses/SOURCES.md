## 変更した依存と overlay

root manifest の builtin-baseline は 04a9d8e5212d01ee1dd9478eadd9caade4f8b0d4。libjxl、libpng、zlib、libjpeg-turbo、AOM、libyuv、libwebp は vcpkg-overlays/security-sec-maint-v013 から選択します。Brotli は security-sec-br1、Highway は Shipping Privacy v2 の port を使います。残りは固定 registry を参照します。

libjxl・Highway の診断用ファイル識別子、libjxl の依存解決、libpng／zlib の共有ターゲット、TurboJPEG の外部 libspng／zlib リンクは当地の overlay に記録しています。AOM は公式 vcpkg port 由来のパッチを維持します。libyuv には上流の 826ab02fcc1af3f45041cef574b318b659802f5d、libwebp には上流の 27e559f5b05d0ed1678ad57fe23f3b667405d11c に基づく最小修正を適用します。

AOM・libyuv の固定 Git commit／tree、SHA-512、ファイル台帳と Git バージョンは cmake/security/sec-maint-v013/5/source-inputs-v1.json にあります。静的組込みは管理対象の JPEGli／Highway と、使用したヘッダー・CRT startup 等の既存契約に従います。
